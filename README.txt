BOOKING DIARY — ANDROID + IPHONE DIRECT-USE PWA

This folder is already built. No npm, coding or build command is needed.

HOW TO USE ON BOTH PHONES
1) Upload all files from this folder to any HTTPS website/folder (Hostinger public_html is fine).
2) Open that URL on the phone.
3) Android: Chrome menu > Install app / Add to Home screen.
4) iPhone: Safari > Share > Add to Home Screen.

After first load, the app works offline and stores booking details on that phone/browser.

2-DAY REMINDERS
- The app shows due reminders when opened and can show browser notifications while supported.
- For a reliable alert even when the app is closed on both Android and iPhone, open a booking and tap:
  "Add 2-Day Phone Calendar Reminder"
  This creates a phone-calendar event with a 2-day alarm.

IMPORTANT
A completely web-based app cannot guarantee an exact future background notification on every iPhone/Android browser without a push server. A native iPhone app also requires Apple signing/TestFlight/App Store. This PWA is the simplest single version that runs on both platforms.

DATA
Bookings are stored locally on the device. Use Settings > Export CSV for backup.
